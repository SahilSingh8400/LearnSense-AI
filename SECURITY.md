# Security Policy

## Supported Versions

The following versions of LearnSense-AI are currently supported with security updates.

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes |
| Below 1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in LearnSense-AI, please help us keep the project secure by reporting it responsibly.

**How to report:**
- Do not create a public GitHub issue for security vulnerabilities.
- Report the vulnerability privately through GitHub's Security Advisories feature.
- Provide a clear description of the vulnerability.
- Include steps to reproduce the issue, if possible.

## What to Expect

- We will review your report.
- We will investigate and verify the issue.
- We will work on a fix if the vulnerability is confirmed.
- We will provide updates regarding the resolution.

## Security Best Practices

- Always use the latest supported version.
- Never share API keys, passwords, or sensitive information.
- Keep dependencies updated.
- Do not commit secret credentials to the repository.

Thank you for helping make LearnSense-AI more secure!
